# INVARIANTS

Every invariant maps to the test files that fail if it is broken. Levels: **unit** (pure domain code), **integration** (real PostgreSQL via Testcontainers), **e2e** (real Next build, worker, Mailpit and a fake Razorpay server in a browser).

Status meanings: **Verified** = the tests ran green in this repository on the date shown. **Not started** = no test yet. No row says Verified until the whole suite has been run after the last code change.
